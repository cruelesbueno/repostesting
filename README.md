# Repostesting 🚀

Este es mi primer repositorio de pruebas en Parrot Linux usando Git y GitHub por SSH.

## 💻 Tecnologías usadas

- Parrot OS
- Git (control de versiones)
- GitHub (repositorio remoto)
- bspwm + Kitty terminal
- SSH para autenticación segura

## 📌 Objetivo

- Practicar el flujo completo de trabajo con Git y GitHub.
- Aprender a usar SSH para autenticar sin contraseñas.
- Subir archivos, scripts y documentación desde Linux.
- Preparar proyectos reales para entrevistas y portafolio.
